# Home Camera Service

Система видеонаблюдения с веб-интерфейсом для локального использования. Запись 24/7 с автоматической ротацией файлов и удалением старых записей при достижении лимита хранилища.

---

## Возможности

- **Выбор камеры** при запуске из списка доступных устройств
- **Веб-интерфейс** с просмотром в реальном времени (MJPEG-стрим)
- **Запись 24/7** с возможностью временного отключения
- **Сегментирование записи** (настраиваемая длительность сегмента)
- **Автоматическое удаление** старых записей при достижении лимита (по умолчанию 100 ГБ)
- **Скачивание файлов** записанных сегментов
- **Автоматическое переподключение** при потере камеры
- **Минималистичный веб-интерфейс** (работает без интернета)
